# AnonyHost
**AnonyHost** turns your local PC into a DarkWeb Server and Host any website on the Dark Web without a public IP, domain, or rented server.

### Features
*   **No Infrastructure Needed:** No public IP, DNS, or hosting provider required.
*   **Universal Hosting:** Supports any web stack (HTML, PHP, Python, etc.), not just static sites.
*   **Easy Deployment:** Upload files or ZIP archives directly.
*   **Persistent `.onion` Address:** Get a stable link that survives restarts.
